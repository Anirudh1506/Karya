## Realistic scenario

The participant is working on a research assignment with source notes, a draft argument, and an unrelated class competing for attention. They receive one new thought during the session and need to recover earlier evidence without remembering where it was stored.

Do not teach feature names or direct the participant to Continue Working, Search, or Quick Capture. State the work goal and observe their natural path.

Rule 0 applies: if the participant does not understand or naturally choose an experience, record a product failure and investigate why. Do not defend the intended philosophy or teach the expected behavior during the measured task.

## Session tasks

1. Resume the research assignment started previously.
2. Capture an incoming thought without abandoning the current train of work.
3. Add substantive text to the draft and continue for at least 20 minutes.
4. Find a previously created source note by what the participant remembers about it.
5. Switch to the unrelated class, do a small edit, then return to the research assignment.
6. Quit or terminate Karya after committed work, relaunch it, and continue.
7. Repeat the resumption check on the next calendar day.

## Observed evidence reported 2026-07-17

> “When a big folder with large files like a project is getting imported, the user is not able to do anything else. The user should be able to cancel, browse other folders or files, or use other Profiles and Workspaces.”

> “When a folder is linked, double clicking it does not open the folder in the system. It opens the folder in Karya where nothing is present.”

> “The upload speed is very bad. Importing one project took a lot of time. Leave folder importing for now and focus on referencing files and folders. Karya Account sync should only back up Karya-native applications like notes, reminders, and calendar.”

Literal interpretation under Rule 0:

- Folder import failed responsiveness and parallel work.
- Referenced-folder activation failed navigation and system delegation.
- Filesystem import failed the current product workflow and is removed from the v1.0 Alpha product entry points.
- Referenced Resource synchronization must remain metadata-only; external content is not Karya-owned data.

Exact elapsed time and interaction counts were not supplied and remain missing evidence.
